# 机上決戦！消しゴム落とし / Eraser Battle

平成学校ゲームズシリーズ第三弾のスマホ向けブラウザゲームです。

机の上で消しゴムを弾いて相手を落とす、平成の休み時間あるあるをテーマにしたスマホ向けブラウザゲーム。スワイプで自分の消しゴムを弾き、相手の消しゴムを机の外へ落とせば勝利です。

## 掲載用紹介文

「机上決戦！消しゴム落とし」は、平成の学校の休み時間に遊んだ消しゴム落としをモチーフにしたミニゲームです。スワイプで自分の消しゴムを弾き、相手の消しゴムを机の外へ落とせば勝利。ギリギリで残る奇跡や、自分だけ落ちる自爆ショットなど、短時間で笑える勝負が楽しめます。

## 操作方法

1. タイトル画面で「ゲーム開始」をタップします。
2. 自分の消しゴム `HEISEI` をタッチします。
3. 指を動かして方向と強さを決めます。
4. 指を離してショットします。
5. 相手の消しゴム `BATTLE` を机の外へ落とせば勝利です。

## 注意事項

- 実在ブランドの消しゴムを連想させないオリジナルデザインです。
- スマホ縦画面をメインに設計しています。
- 平成学校ゲームズシリーズの第三弾です。
- MVP v0.1ではゲーム中広告を入れていません。
- 効果音は外部音声素材に依存せず、Web Audio APIで軽量に生成しています。
